### 🧠 LLMs From Scratch
**Learning the foundations behind modern language models by implementing the building blocks directly in PyTorch.**

- Tokenization and text data pipelines
- Attention and multi-head attention
- GPT-style architecture
- Pretraining and generation
- Classification and instruction fine-tuning
- LoRA / parameter-efficient fine-tuning concepts

→ [View project](https://github.com/sujanMidatani7/LLMs-from-scratch)

### 🛡️ OpenEnv Multimodal Moderation
**Production-oriented multimodal moderation environment with an explicit analyze → retrieve → decide → review → finalize workflow.**

- FastAPI-based environment server
- Policy retrieval / grounding layer
- Typed state and episode-based evaluation
- Deterministic inference flows
- Dockerized deployment
- OpenAI-compatible model integration

→ [View project](https://github.com/sujanMidatani7/openenv-multimodal-moderation)

### 🎤 Interview Evaluation System
**End-to-end AI pipeline for evaluating candidates from resumes, generated questions, spoken answers, and model-based grading.**

- Resume information extraction
- Question generation
- Speech-to-text pipeline
- Per-question evaluation
- Embeddings + Pinecone retrieval
- Final interview scoring

→ [View project](https://github.com/sujanMidatani7/InterviewEvaluationSystem)

### 🧩 Persona & Evaluation APIs
Building API-first systems around **LLM evaluation, personas, structured outputs, and AI-assisted assessment workflows**.
